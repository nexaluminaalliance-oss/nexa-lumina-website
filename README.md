# Nexa Lumina Alliance Website

Initial production-oriented landing site for Nexa Lumina Alliance.

## Source basis

The information architecture and copy are grounded in the current NLA project documents:

- Partnership & Company Profile
- Strategic Architecture & Partnership Framework
- Government & Regulatory Business Profile
- Clean Energy Procurement Signal Brief
- Primary Operations Money Trail Framework
- Action Board

The source material defines NLA as a multi-sector enterprise with clean energy as its primary operating focus, with current commercial activity centered on procurement support, supplier coordination, contractor engagement, project facilitation and strategic partnerships.

## Current state

This is the first implementation pass. It is intentionally a static, responsive site with no backend dependency.

## Commercial principle

The site exists to turn attention into qualified business conversations. It should not claim supplier authorization, project history, certifications, pricing or capabilities that have not been verified.
